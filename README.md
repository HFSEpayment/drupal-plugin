# Инструкция по установке платёжного плагина HB Epay для Drupal Commerce

## Общие сведения

Плагин оплаты для CMS Drupal (Commerce):
- обеспечивает приём платежей через HB Epay (Halyk Bank);
- поддерживает передачу товарной корзины (заказа) в платёжный шлюз;
- реализован как off-site redirect / встроенный JS-виджет платёжной страницы HB Epay.

## Версия и совместимость

Плагин разрабатывался под **Drupal 11.x** и Commerce 2.x.

⚠️ **Важно:** при установке на версии Drupal (7.x/9.x/10.x) модуль в исходном виде **возможно не заработает**. Для версии Drupal (7.x/9.x/10.x) смотреть https://github.com/HFSEpayment/drupal-plugin/releases/tag/8x.

## Установка Commerce и зависимостей

1. Установить Commerce и дополнительные модули при необходимости.
2. После того как все дополнительные модули установлены, отметить всё необходимое.
3. Нажать «Установить».
4. Перейти в «Отчёты» → «Состояние сайта» (в старых версиях — «Пакеты» / Status report).
5. Проверить установку всех пакетов. Если какие-то не установлены — скачать пакеты и установить по указанному в отчёте адресу/способу.

*(Скриншоты шагов 1–5 — см. приложение к документу.)*

## Установка модуля HB Epay

6. Для установки HB Epay в административной панели перейти в «Расширения» → «Установить новый модуль».
7. Выбрать zip/tar.gz-архив, скачанный из репозитория → нажать «Установить».

⚠️ **Проверка перед установкой:** откройте файл `hbepay.info.yml` внутри архива и убедитесь, что в нём присутствует строка:
```yaml
core_version_requirement: ^9 || ^10 || ^11
```
Без этого ключа современный Drupal откажется распознавать модуль с ошибкой `InfoParserException: The 'core_version_requirement' key must be present`. Если строки нет — добавьте её в `.info.yml` до загрузки архива.

8. Перейти в «Расширения», поставить галочку напротив **HB Epay**, спуститься в конец страницы и нажать «Установить».

## Настройка платёжного шлюза

9. Перейти: **Commerce → Конфигурация → Payment gateways → Add payment gateway**.
10. Заполнить настройки:

| Поле | Значение |
|---|---|
| Название | HBPay |
| Плагин | HB Epay Payment Gateway |
| Режим | Тестовый (test) или боевой (prod) |
| Description | Произвольное описание (необязательно) |
| Client ID | выдаётся банком |
| Client Secret | выдаётся банком |
| Terminal | выдаётся банком (ID точки продаж/терминала) |

Нажать «Сохранить».

## Тестирование

11. Добавить товар в корзину и перейти к оформлению заказа.
12. На шаге оплаты выбрать HB Epay, дождаться загрузки платёжного виджета и провести тестовую оплату.
13. Проверить в «Commerce → Заказы», что заказ получил статус оплаченного, а в записи платежа (`commerce_payment`) корректно указан `payment_gateway`.

Если на любом из шагов 6–13 возникает ошибка — сверьтесь с логами:
```
/admin/reports/dblog
```
или включите подробный вывод ошибок в `settings.php`:
```php
$config['system.logging']['error_level'] = 'verbose';
```
